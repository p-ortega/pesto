<objective>
The last of the phase's three capabilities: pesto can now say whether a run's cache is still good.

Each artifact in the cache records which source files it came from, and each of those records carries
size, mtime and a whole-file sha256. Opening a run compares size and mtime first — cheap, and right
almost always — and only reads and hashes the files where those disagree. That two-tier shape is not
an optimisation; it is the only shape that satisfies both halves of the problem. Hashing the whole
3.5 GB benchmark run costs about 2 s on local SSD and about 30 s over the external USB drive, which
puts M0's 1.5 s warm-open budget out of reach. Trusting size and mtime alone re-ingests 11 GB every
time a run is copied off the backup drive, because copying rewrites every mtime while changing no
content.

Purpose: make "is this cache still valid?" answerable in the warm-open budget, and answerable
honestly — fresh only when freshness can be proved.
Output: `SourceFingerprint`, `Artifact` and `Manifest`, the schema every later phase's ingest code
writes into.
</objective>

    `Artifact` is a plain dataclass: `name: str`, `state: ArtifactState`, `reason: str | None = None`,
    `sources: list[SourceFingerprint] = field(default_factory=list)`.

    `Manifest` is a dataclass: `cache_version: int`, `run_dir: str`,
    `artifacts: dict[str, Artifact] = field(default_factory=dict)`. `Manifest.empty(run_dir)`
    constructs one at the current `CACHE_VERSION` with the run directory as a string.
    `mark_ok(name, sources)` stores an `ok` artifact with a copy of the fingerprint list;
    `mark_failed(name, reason)` and `mark_missing(name, reason)` store the state with its reason and
    no sources. Keeping the reason is what lets a later phase report a failure by artifact name and
    cause instead of a silent absence.

    `is_stale(name)` returns True when the artifact is absent or its state is anything other than
    `ok`, and otherwise returns `not all(source.matches(Path(self.run_dir)) for source in
    artifact.sources)`. Every unknown resolves to stale.

    `_write_atomic(target: Path, payload: str) -> None`: write the payload to a
    `tempfile.NamedTemporaryFile(delete=False)` created **in the target's own directory** so the final
    step stays on one filesystem, flush and `os.fsync` it, close it, then `os.replace(tmp, target)`.
    `os.replace` is atomic on POSIX and on Windows, so a reader sees either the whole previous
    manifest or the whole new one. Remove the temporary file in a `finally` if the replace did not
    happen, so a failed save leaves no litter in the cache root.

    `save(layout)` calls `layout.ensure()`, builds the payload as
    `{"cache_version": ..., "run_dir": ..., "artifacts": {name: asdict(artifact)}}` serialised with
    `json.dumps(..., indent=2)`, and writes it through `_write_atomic(layout.manifest, payload)`.
    `asdict` flattens the nested fingerprints including the new `checksum` field; the round-trip test
    above is what holds that true.

    `load(layout)` reads `layout.manifest` inside `try/except (OSError, json.JSONDecodeError)` and
    returns `cls(cache_version=CACHE_VERSION, run_dir="")` from the except branch — a manifest that is
    absent, unreadable or not valid JSON yields no artifacts, so everything is stale. When the parsed
